# Спроси про физику — вопросы и ответы

Сайт с ответами на вопросы по докладу «Известные физики» (**7 класс, школа № 81, Ярославль**).

**Автор:** Кабанов Константин Павлович (Костя), 7-9 класс, школа № 81, город Ярославль, Россия.

## Что это

Два раздела:

1. **💬 Чат с ИИ** — одноклассник пишет вопрос своими словами, отвечает ИИ.
   У ИИ есть промт со всей презентацией, поэтому он отвечает именно по докладу.
   Если спросят «кто это сделал?» — ИИ назовёт автора проекта.
2. **📚 База ответов** — 59 готовых вопросов с ответами по 7 темам.
   Работает даже без интернета: если ИИ недоступен, ответ ищется в базе.

## Файлы

| Файл | Что это |
|------|---------|
| `index.html` | весь сайт: тексты, стили и код внутри |

## Как открыть

Просто откройте `index.html` в браузере — ничего устанавливать не нужно.

## Режимы ИИ

Кнопка **⚙ Настройки** в чате:

| Режим | Что делает |
|-------|------------|
| 🧠 Бесплатный ИИ (без ключа) | по умолчанию, ничего настраивать не надо |
| 🔑 Свой API-ключ | Groq / OpenRouter / Google Gemini — если бесплатный перегружен |
| 📚 Только база знаний | без интернета, отвечает по 59 готовым ответам |

## Как изменить

Всё внутри `index.html`:

- `QA` — массив вопросов и ответов (`c` — тема, `q` — вопрос, `a` — ответ);
- `SYSTEM_PROMPT` — промт для ИИ со всем контекстом презентации и именем автора;
- `SUGGEST` — подсказки на стартовом экране.

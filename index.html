Настройки ИИ

Сейчас бесплатный ИИ без ключа (сервис pollinations) работает не всегда: он пускает только один запрос зараз и иногда отвечает «лимит исчерпан». Сайт это понимает: повторяет запрос, пробует запасной вход и, если ничего не вышло, сам отвечает по базе знаний — без английских ошибок на экране. Чтобы ИИ отвечал всегда, вставь свой бесплатный ключ (GitHub Models — там есть DeepSeek).

🔒 Ключ (если вставишь) хранится только в этом браузере и никуда не отправляется, кроме самого сервиса ИИ. В файл сайта он не записывается.

Где взять ключ:
• GitHub Models — github.com/settings/personal-access-tokens (галочка Models: read). Аккаунт GitHub уже есть — это самый простой путь, и там работает DeepSeek.
• console.groq.com · openrouter.ai/keys · aistudio.google.com
